# CPU Scheduling Scenarios

## Formulas

- **TAT** (Turnaround Time) = Completion – Arrival
- **WT** (Waiting Time) = TAT – Burst
- **RT** (Response Time) = Start – Arrival

---

## Scenario A: Basic Mixed Workload

| Process | Arrival | Burst | Priority |
| ------- | ------- | ----- | -------- |
| P1      | 0       | 5     | 2        |
| P2      | 1       | 3     | 1        |
| P3      | 2       | 4     | 3        |

**Quantum = 3**

### Priority Scheduling

| Process | TAT        | WT        | RT        |
| ------- | ---------- | --------- | --------- |
| P1      | 8–0 = 8    | 8–5 = 3   | 0–0 = 0   |
| P2      | 4–1 = 3    | 3–3 = 0   | 1–1 = 0   |
| P3      | 12–2 = 10  | 10–4 = 6  | 8–2 = 6   |
| **Total** | **21**   | **9**     | **6**     |
| **AVG**   | 21/3 = **7** | 9/3 = **3** | 6/3 = **2** |

**Gantt Chart:**

| P1 | P2 | P3 |
| -- | -- | -- |
| 0 → 5 | 5 → 8 | 8 → 12 |

### Round Robin

| Process | TAT        | WT         | RT        |
| ------- | ---------- | ---------- | --------- |
| P1      | 11–0 = 11  | 11–5 = 6   | 0–0 = 0   |
| P2      | 6–1 = 5    | 5–3 = 2    | 3–1 = 2   |

| **Total** | **26**   | **14**     | **6**     |
| **AVG**   | 26/3 = **8.67** | 14/3 = **4.67** | 6/3 = **2** |

**Gantt Chart:**

| P1 | P2 | P3 | P1 | P3 |
| -- | -- | -- | -- | -- |
| 0 → 3 | 3 → 6 | 6 → 9 | 9 → 11 | 11 → 12 |
